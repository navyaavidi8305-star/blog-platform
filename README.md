# BlogSphere – MERN Stack Blog Platform

## Project Overview

BlogSphere is a full-stack blogging platform developed using the MERN stack (MongoDB, Express.js, React.js, Node.js). The application allows users to create accounts, publish blog posts, interact through comments, and manage content securely using JWT authentication.

This project was developed as the final project for a remote internship to demonstrate full-stack development concepts, REST API integration, authentication, database management, and deployment.
